`doorway.svg` is an original illustration authored for this project on 2026-10-18, not a reproduction of a painting. It depicts an ochre doorway opening onto a second mountain landscape, two moons, suspended stones, and a shadow that bends against the light. Gradients model light and stone; fixed-seed SVG grain supplies a dry painted-paper finish. No external sources, fonts, libraries, or embedded raster images. Project usage is unrestricted by any third-party artwork license.

- Intrinsic dimensions: 720 × 900; 4,340 bytes at creation.
- Desktop: complete landscape beside, never behind, the reading column.
- Phone: miniature landscape above the reading area, preserving the arch and moon.
- Decorative (`alt=""`, enclosing `aria-hidden`), non-interactive, with reserved dimensions. Text and controls do not depend on successful loading.
- No random geometry or animation. The SVG turbulence seed is fixed.
